# Voice design

Creates a new voice from a natural-language description and reads the supplied text.

## How to use

1. Describe age, pitch, timbre, volume, accent, emotion, fluency, speed, clarity, intonation, and personality.
2. Audition with a short sentence, then save an accepted result as a later reference.
3. Blind-review multiple seeds for the same description.

## Important

Keep character plot instructions out of the acoustic description. If output is noise, verify the Full model and official parameter path.
