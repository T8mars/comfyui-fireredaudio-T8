# Creative line candidate pool

Generates anonymous performance variations for one existing line ID and can include the original take in the blind review.

## How to use

1. Connect exactly one line ID at a time.
2. Keep the original take in the pool so a new variation must actually win the listening review.
3. Connect to Take Review Board, then Apply Creative Candidate.

## Important

The node never replaces source audio automatically. Seeds, duplicate hash groups, and provenance are recorded in the manifest.
