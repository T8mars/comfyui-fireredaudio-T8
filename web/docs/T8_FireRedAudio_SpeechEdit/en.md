# Speech edit

Performs semantic insertion, deletion, replacement, or upstream acoustic edit templates.

## How to use

1. Replace example: `Replace the last sentence with: What are you doing?`
2. Delete example: `Delete the second sentence`; insert example: `Insert after the first sentence: Welcome back.`
3. Use Parametric Acoustic Edit for pitch, speed, and volume to avoid malformed commands.

## Important

The instruction targets content actually present in the audio. Listen first and identify the sentence unambiguously.
