# Multi-seed audition

Generates anonymous takes for a new line and can produce a suggestion from ASR and audio proxy metrics.

## How to use

1. Filenames hide the seed for blind listening.
2. Connect `all_takes` to the Take Review Board.
3. The automatic suggestion is a filter, not a substitute for listening.

## Important

Use this for new copy. Use Creative Line Candidate Pool for a line already inside an AudioBatch.
